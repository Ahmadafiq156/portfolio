# Ahmad Afiq Portfolio — GitHub Pages Edition

This is the complete static version of Ahmad Afiq's charcoal-and-teal portfolio.
It uses only HTML, CSS, and JavaScript, so GitHub Pages can publish it directly
without Node.js, npm, React, or a build command.

## Main files

- `index.html` — all portfolio content and links
- `style.css` — complete responsive design
- `script.js` — rotating role, mobile menu, reveal animation, and active navigation
- `assets/` — project images, portrait, favicon, and social preview
- `Ahmad_Afiq_CV.pdf` — résumé opened by the résumé buttons
- `.nojekyll` — disables GitHub's Jekyll processing
- `CUSTOM-DOMAIN-GUIDE.md` — complete domain and DNS instructions

## Publish on GitHub Pages

1. Open the GitHub repository that publishes your current portfolio.
2. Upload every file and folder from this package to the repository root.
3. Commit the upload to the `main` branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select **main** and **/(root)**, then click **Save**.
7. Wait for GitHub Pages to finish publishing.

Your existing project repository normally appears at:

`https://ahmadafiq156.github.io/portfolio/`

For the custom domain setup, continue with `CUSTOM-DOMAIN-GUIDE.md`.

## Editing later

- Change text and links in `index.html`.
- Change colors and layout in `style.css`.
- Replace an image in `assets/` while keeping the same filename.
- Replace `Ahmad_Afiq_CV.pdf` to update the résumé without changing links.
